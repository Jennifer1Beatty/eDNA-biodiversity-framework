eDNA Interactive Framework

Each section represents a key decision point in the utilization of eDNA for biodiversity monitoring and provides example workflows. Click on the button for information on the choices involved in each step and for resources to guide decision making. Thorough documentation and metadata is essential for successful eDNA studies that adhere to FAIR policies and are comparable.

  1. User case: Example data types or policy questions for implementing eDNA.
  2. Method Choice: Information on the selectivity and readiness of environmental DNA methods for policy integration.
  3. Sample Processing: Field and lab actions to generate DNA sequences. End product: Metadata and raw sequence tables.
  4. Sequencing Processing: Key steps in the bioinformatic pipelines used for DNA sequence processing. End product: Taxonomy tables and metadata files.
  5. Data Analysis: The types of biodiversity data that each method can provide. End product: Biodiversity metrics and/or taxa abundance for generating essential variables and metadata files.
  6. Policy Indicators: European Union policy frameworks suited for integration with eDNA datasets. Final formats, metadata schemas, and submission keys required for uploading reporting parameters to central biodiversity open access portals.
